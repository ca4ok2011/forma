## Что умеет

| Раздел | Возможности |
|---|---|
| **Сегодня** | Сводка дня: калории, вода, тренировка, прогулка, вес, достижения, итоги 7 дней |
| **Еда** | База из 320+ продуктов, порции поштучно (яйцо, банка энергетика 0,45 л, ломтик, ложка), напитки в мл, **сканер штрихкодов** (данные с упаковки из Open Food Facts), свои продукты, избранное, «как вчера», Б/Ж/У и памятка для новичков |
| **Блюда и шаблоны** | Свои рецепты из продуктов (плов, омлет) — калории и БЖУ на порцию считаются сами; шаблоны приёмов пищи («мой завтрак») добавляются в один тап |
| **Подсказка «что доесть»** | После 15:00 подбирает 2–3 варианта из привычной еды и белковых продуктов, чтобы закрыть калории и белок |
| **Вода** | Норма по весу, типы напитков, напитки из «Еды» засчитываются автоматически (кроме алкоголя) |
| **Зал** | 68 упражнений с фото и схемой мышц, подходы и вес, 1 или 2 гантели, кардио с отрезками (разный наклон/скорость), таймер отдыха, рекорды, прогресс силы и выносливости, карта мышц |
| **Прогулки** | Шаги → километры и калории по твоему росту, весу и полу, цель на день, календарь, прогресс по дням и неделям. **Шаги из «Здоровья» iPhone** подтягиваются сами |
| **Вес** | Дневник веса, тренды за неделю и месяц, график |
| **Достижения** | 13 достижений × 3 уровня (бронза, серебро, золото) — считаются по дневнику |

Калории считаются честно: цель дня = обмен веществ (Миффлин — Сан Жеор) × активность + сожжённое в зале и на прогулках ± дефицит/профицит под цель.

## Установка на iPhone

1. Открой **[ca4ok2011.github.io/forma](https://ca4ok2011.github.io/forma/)** в **Safari**.
2. Нажми **«Поделиться»** → **«На экран «Домой»»**.
3. Запускай с иконки — приложение работает на весь экран и без интернета.

> Данные Safari-вкладки и приложения с экрана «Домой» хранятся раздельно. Пользуйся чем-то одним — лучше иконкой.

**Android:** открой ссылку в Chrome → меню ⋮ → **«Добавить на главный экран»**.

## Синхронизация между устройствами

Данные можно хранить в своём **секретном Gist на GitHub** — тогда они одинаковые на телефоне и компьютере и не пропадут, даже если удалить приложение.

1. Создай токен: [github.com/settings/tokens/new?scopes=gist](https://github.com/settings/tokens/new?scopes=gist&description=Forma%20sync) — галочка **gist** уже стоит, срок **No expiration** → **Generate token**.
2. В приложении: «Настройки» → «Синхронизация устройств» → вставь токен (`ghp_…`) → **Подключить**.
3. На другом устройстве или после переустановки вставь тот же токен — записи объединятся.

Синхронизация идёт сама: после каждого изменения, при открытии приложения и раз в полторы минуты. Новые записи с разных устройств сохраняются, удалённые — не возвращаются. Токен хранится только на устройстве.

## Шаги из «Здоровья» iPhone

Работает поверх синхронизации: команда iPhone («Команды» → автоматизация по времени) берёт шаги за день из «Здоровья» и кладёт маленький файл `steps-ГГГГ-ММ-ДД.json` в тот же секретный Gist. Приложение при синхронизации переносит шаги в «Прогулки» и убирает старые файлы.

Пошаговая инструкция с кнопками «Скопировать» — в приложении: «Настройки» → «Шаги из «Здоровья» iPhone».

Как считается: «Здоровье» даёт все шаги за день, прогулки, записанные вручную, уже внутри них — дважды не считаются. Первые 3 000 шагов — обычный быт, он уже заложен в образ жизни из настроек, калории идут с остальных.

## Данные и приватность

- Всё хранится **на устройстве** (localStorage + копия в IndexedDB). Если включить синхронизацию — ещё и в твоём секретном Gist. Других серверов и аккаунтов нет. При сканировании штрихкода приложение запрашивает только этот номер в открытой базе Open Food Facts.
- **Обновление приложения не трогает данные** — меняются только файлы самого приложения.
- Перед первым запуском каждой новой версии приложение само делает внутренний снимок данных.
- Сделай **резервную копию**: «Настройки» → «Данные» → «Резервная копия». Восстановление — «Восстановить из копии» (существующие записи не затираются).
- Без синхронизации данные пропадут, если удалить приложение с экрана «Домой», очистить данные Safari или сменить адрес сайта. С синхронизацией — просто вставь токен снова.

## Как обновить сайт (для владельца репозитория)

1. На GitHub открой репозиторий → **Add file** → **Upload files**.
2. Перетащи все файлы из архива — `index.html`, `sw.js`, `manifest.webmanifest`, `README.md` и папки `icons/`, `lib/`, `ex/` → **Commit changes**.
3. Через 1–2 минуты GitHub Pages опубликует изменения. На телефоне закрой и снова открой приложение — номер версии виден внизу настроек.

Первичная настройка Pages: **Settings → Pages → Deploy from a branch → `main` / `(root)`**.

## Структура

```
index.html             приложение целиком (HTML + CSS + JS в одном файле)
sw.js                  service worker: офлайн-режим и кэш файлов
manifest.webmanifest   название, цвета и иконки для установки
icons/                 иконки приложения (180, 192, 512, maskable)
fonts/                 шрифты Manrope и Unbounded (локально, без Google Fonts)
ex/                    фото упражнений (webp)
lib/                   распознаватель штрихкодов ZXing (грузится только при сканировании)
```

Сборки нет — это статичный сайт, его можно открыть с любого хостинга.
